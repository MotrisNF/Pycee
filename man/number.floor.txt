# number.floor math.floor
NAME
    number.floor - the largest int not above x: x.floor(), math.floor(x)

SYNOPSIS
    x.floor()
    math.floor(x)

DESCRIPTION
    Rounds down, toward minus infinity: 3.7 gives 3, -3.2 gives -4. An
    int stays as it is.

ERRORS
    ValueError, OverflowError   nan; inf or a float too large.

EXAMPLES
    >>> 3.7.floor()
    3
    >>> (-3.2).floor()
    -4

SEE ALSO
    man(number.ceil), man(number.trunc), man(number.round)
