# IOError
NAME
    IOError - a failure of files or of the system

DESCRIPTION
    Raised by io and os when the system refuses something, with the
    system's reason and the path: "is a directory", "directory not
    empty", "file exists", "not a directory"... and when a file is used
    the wrong way (reading one open for writing, using a closed one).
    Two kinds have their own type, so except IOError catches them too:
    FileNotFoundError and PermissionError.

EXAMPLES
    >>> import io
    >>> io.read_file("/")
    IOError: is a directory: "/"

SEE ALSO
    man(FileNotFoundError), man(PermissionError), man(io), man(os)
