# for
NAME
    for - walk the items of a collection, one by one

SYNOPSIS
    for (item in iterable) { ... }
    for (a, b in iterable) { ... }
    for (item in iterable) { ... } else { ... }

DESCRIPTION
    Runs the block once for each item, with the variable holding it. The
    variable is a vemp of the block: it exists only inside it.

    What it walks:
        range(...)   its numbers (see man(range))
        list, tuple  their items, in order
        string       its characters, each a string of length 1
        set          its items (in insertion order)
        dict         each pair as a dict of length 1; with two names,
                     for (k, v in d) gives each key and its value
        file         its lines, each with its "\n" (see man(file))
        an object    with an iter() method (see man(obj))
    for (a, b in it) unpacks each item (a tuple or list of 2) into a and
    b: for (i, x in l.enumerate()) gives each index and item.

    A list must not change size while a for walks it: that is a
    RuntimeError (items would be skipped or seen twice). Walk a copy
    (l.copy()) to change the original.

    The else block runs only if the loop ended without a break: useful
    for "searched everything and did not find it".

    break leaves the loop, continue goes to the next item; break outer
    and continue outer act on the loop around the current one.

ERRORS
    TypeError       walking something that is not iterable (a number).
    RuntimeError    the list changed size while it was walked.
    AssignmentError unpacking an item with a different number of names.

EXAMPLES
    >>> for (c in "abc") { print(c); }
    a
    b
    c
    >>> for (i, x in ["a", "b"].enumerate()) { print(i, x); }
    0 a
    1 b
    >>> for (k, v in dict("x": 1, "y": 2)) { print(k, v); }
    x 1
    y 2
    >>> for (n in [1, 3, 5]) {
    ...     if (n % 2 is 0) { break; }
    ... } else {
    ...     print("no even number");
    ... }
    no even number
    >>> for (n in 42) { }
    TypeError: 'number' object is not iterable

SEE ALSO
