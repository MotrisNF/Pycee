# set
NAME
    set - a collection without repeated values

SYNOPSIS
    set(1, 2, 3)     set()     set(x for (x in l))     l.to_set()

DESCRIPTION
    A set holds each value once: adding one it already has does nothing.
    It is made with set(...) (no literal) and shown as set(1, 2). Its
    type is "set". Its items are kept in the order they were added, but
    do not rely on any order. Like dict keys, the items must be values
    that cannot change (numbers, strings, bools, none, ranges, tuples of
    those).

    x in s and s.has(x) are fast, whatever its size: use a set to know
    whether a value was seen. a is b compares the items in any order.
    for walks its items. No indexes, no slices.

METHODS
    Each one has its page: man(set.<method>).
    len(), add(x), remove(x), has(x), clear(), copy()
    union(s), intersection(s), difference(s)      new sets
    to_list(), to_tuple(), sum(), min(), max()
    add, remove and clear give back the set itself (they chain).

ERRORS
    TypeError     an item that can change (a list, a set, an object).
    ValueError    remove(x) of a value that is not there.

EXAMPLES
    >>> var s = set(3, 1, 3, 2)
    >>> s
    set(3, 1, 2)
    >>> s.add(4).has(4)
    true
    >>> set(1, 2, 3).intersection(set(2, 3, 4))
    set(2, 3)
    >>> set(c for (c in "banana")).len()
    3
    >>> set([1])
