# list.insert
NAME
    list.insert - add an item at a position

SYNOPSIS
    l.insert(i, x)

DESCRIPTION
    Puts x at index i, moving the items from i on one place to the
    right. A negative i counts from the end; an i past either end puts x
    at that end (no error). Gives back l.

EXAMPLES
    >>> [1, 3].insert(1, 2)
    [1, 2, 3]
    >>> [1, 2].insert(10, 3)
    [1, 2, 3]
    >>> [1, 2].insert(0, 0)
    [0, 1, 2]
