# set.union set.intersection set.difference
NAME
    set.union - combine two sets: union, intersection, difference

SYNOPSIS
    a.union(b)   a.intersection(b)   a.difference(b)

DESCRIPTION
    New sets (a and b do not change):
        union          the items in a or in b
        intersection   the items in both
        difference     the items of a that are not in b
    b must be a set too (convert with to_set()).

EXAMPLES
    >>> set(1, 2).union(set(2, 3))
    set(1, 2, 3)
    >>> set(1, 2, 3).intersection(set(2, 3, 4))
    set(2, 3)
    >>> set(1, 2, 3).difference(set(2))
    set(1, 3)
